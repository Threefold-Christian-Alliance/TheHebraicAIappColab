# Ideas for a public Hebraic.ai API (planning, 2026-11)

Status: ideas only. Nothing here is built or promised.

1. **Translation-aware verse auto-linker.** Finds verse references in any text and links them to a reader in the user's language, such as Bibleserver `CBT` for Bulgarian. For church sites, blogs, and newsletters.
2. **Jewish-context passage lookup.** Takes a verse and returns cited scholarly passages from our public-domain library, in any language. For Bible apps and study tools.
3. **Citation-grounded Q&A.** Takes a question in any language and returns an answer in that language, with citations. For ministries and apps.
4. **Hebrew word study.** Returns a word's root, meaning, and usage notes, with library citations.
5. **"Jewish roots" snippet per verse.** A short, cached commentary note for each verse.
6. **Embeddable chat widget.** A drop-in script for church websites.
7. **Sermon-prep context pack.** Takes a passage and returns its background, key Hebrew words, and citations.

Licence note: our library sources are public domain. Most modern Bible translations are not, so the API returns links to translations, not their text.

Recommended first steps: (1) the verse auto-linker and (2) the passage lookup.
