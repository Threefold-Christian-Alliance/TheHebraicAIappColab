# TheHebraicAIappColab

Public collaboration space for **[Hebraic.ai](https://hebraic.ai)** — a Threefold Christian Alliance ministry product (executed by Allegiance Media LLC).

The production application repository remains **private**. This public repo is for transparency and community learning:

- how the knowledge **harness** works (ingest → chunks → embeddings → retrieval)
- **sources** admitted into (or considered for) the harness
- docs, FAQs, and design notes suitable for the public
- issues and discussion that do not require private app code
